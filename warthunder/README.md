# War Thunder 車両名クイズ

公開先： https://manyu-a.github.io/chara-quiz/warthunder/

HTML / CSS / JavaScript の静的サイトです。依存ライブラリやビルドは必要ありません。

## データ

- `vehicles.js`: ゲーム版 **2.59.0.94** の通常研究ツリー用スナップショット。翻訳CSV内の文字列 `\t` は削除して表示・入力判定に使用
- `update_data.py`: [War Thunder Datamine](https://github.com/gszabi99/War-Thunder-Datamine) を参照してデータを再生成する標準ライブラリのみの Python スクリプト
- `weapon_hints.js`: 同じゲーム版の武装ヒント。全2,251車両の主砲、火器、または選択式兵装の区別を保持
- `update_weapons.py`: 同一データマイン版のユニット定義・武器定義から `weapon_hints.js` を再生成
- 同じ国・内部IDに重複が生じないよう抽出し、プレミアム・イベント・所持者限定の列は除外
- 空の航空機には空RB、ヘリには陸RB、陸・海にはそれぞれのRBを使用
- 内部データは `[ID, 国家, 分類, RB, 英語名, 日本語名, 車両種別]` の配列形式
- 車両種別は同じデータマインコミットの `unittags.blkx` の `type_*` タグから取得し、全2,251車両を24区分に分類（不明は出力時にエラー）

## 更新

**公開ライブ版**のデータマインコミットを確認してから、リポジトリルートで実行します。

```bash
python warthunder/update_data.py <公開ライブ版のコミットSHA>
python warthunder/update_weapons.py
```

データマインの `master` には開発サーバー版が混在するため、無確認で最新版の SHA を指定しないでください。車両の追加・削除、名称変更、BR変更を確認してから `vehicles.js` をコミットします。

## 判定・セーブ

- 日本語のゲーム内名称を表示・ヒント・正解メッセージに使用します。英語の正式名称でも回答できます。日本語訳がない場合は英語名のまま表示されます。
- `app.js` は Unicode NFKC 正規化、ひらがな・カタカナ差分、大小文字差分、スペース・句読点・ハイフン・括弧等の全記号の除去を行い、正式名称を比較します
- 「Ⅲ号」「III号」「3号」「三号」のようなローマ数字（I～XX）・算用数字・漢数字の表記揺れを吸収します（例：三式＝3式、三二型＝32型）
- 文字列の部分一致・あいまいな編集距離は使わず、車両の派生型を誤回答として受理しないようにしています
- 国・兵種・BRの組み合わせとゲーム版ごとに、進捗をブラウザの `localStorage` に保存します
- 車両アイコンは名前を正解した際かギブアップ時だけ、[War Thunder Vehicles API](https://github.com/Sgambe33/WarThunder-Vehicles-API) から読み込みます（画像なしでもクイズは使用可能）

## ヒント

- ヒント1：選択した未回答車両の種類（軽戦車・重戦車、戦闘機・爆撃機、駆逐艦・巡洋艦など）を表示
- ヒント2：主武装（地上）、機銃・機関砲（航空機）、主砲（艦艇）、標準火器（ヘリ）を表示。通常武装の口径と数をゲームデータから抽出
- ヒント3：ヒント2の後に解放。従来どおり、日本語名（なければ英語名）の先頭1文字を表示
- 武装はゲームデータの通常装備を優先。装備スロットにのみ火器がある機体は「武装例（装備構成による）」として区別します。固定火器を確認できない機体は「搭載武装は選択式」と表示し、爆弾・ロケット等の可変搭載量は推測しません。
- 3段階とも車両の正解扱いにはしません。ヒント利用で経過時間の計測が始まります

## 名称の表記揺れ・旧名称

- メーカー名の「ビッカース」と「ヴィッカース」は、回答時に同じものとして扱います（表示名は変更しません）。
- 2025年に公式名称が ZSU-23-4 から ZSU-23-4V に変わった3車両（ソ連・イタリア・イスラエル）は、旧名称 ZSU-23-4 でも正解になります。M2/M4は対象外です。
- 略称・過去名称は `app.js` の `answerAliases` にID単位で追加します。曖昧な部分一致は使いません。

## 表記揺れ・日本語名補正（2026-11-02）

- 回答時に「ジャガー／ジャギュア／ジャグア／ヤグアル」「ヴァンパイア／バンパイア」「ゲパルト／ゲパード」「トーネード／トルネード」「レオパルト／レオパルド」を統一（既存のビッカースも維持）。
- 艦艇名としての「レオパール」「レパード」は別扱いとし、一律に統一しない。
- 日本語名の誤記等4件を補正：イタリアOsa-AKMの末尾M、Beaufighter Mk VIcのI/l、Spitfire Mk Vc/tropのtrop区別、ZTS63の1980年型区別。
- これらの補正は生成スクリプトの `JAPANESE_NAME_FIXES` にも記録し、データ更新時に同じ旧表記が残る場合だけ補正する。
- 「Osa-AK」と「Osa-AKM」など型式が異なるものは同一視しない。メーカー名・愛称による別名追加は見送り。

## 欧文アクセント・個別の短縮名（2026-11-02）

- 回答比較では欧文のアクセント記号を無視。`AMX-50 Surbaissé` を `AMX-50 Surbaisse` でも正解にする。日本語の濁点は維持する。
- `Bardelas/60mm HVMS`（イスラエル）のみ、`Bardelas` と `バルデラス` を個別の正解別名として許容する。一般の `/` 以降の削除は行わない。

## 一意な車両系列名の短縮回答（2026-11-02）

- 現行のゲーム版2.59.0.94の研究・プレミアム・イベントなど、ショップ登録車両3,303件を横断調査。別型式がない21車両のみ、番号やMkなどを省略した系列名を `answerAliases` に追加。
- 対象：Zerstörer 45、Begleitpanzer 57、Vextra 105、Tetrarch I、Harry Hopkins I、Brigand B 1、Blenheim Mk IV、Beaufort Mk VIII、Chesapeake Mk I、Firebrand TF Mk IV、Sea Gladiator Mk I、Sea Meteor F Mk 3、Sea Venom FAW 20、Javelin Mk.9、Wessex HU Mk.5、Baleno MC-492、Radkampfwagen 90、Arjun Mk 1、Lago I、Sabra Mk.I、Sagittario 2。
- 省略後に別型式がある Swordfish、Attacker、Sea Hawk、Whirlwind、Jagdpanther、Ram、Zrinyi、同名イベント車両のある Super Mystere は対象外。正式名表示・出題数・保存キーは変更しない。
- 今後のデータ更新では、短縮回答と新規登場した別型式の名称の重複を再確認すること。
