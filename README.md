# トリッカル 全使徒言えるかな？

『トリッカル・もちもちほっペ大作戦』の使徒名当てクイズ（非公式）です。

- グローバル版で2026年10月31日までに実装された82使徒が対象
- 性格別の一覧から、名前を答えると画像が開きます
- ひらがな・カタカナや一部の略称でも回答できます
- マスをタップすると種族・職業・配置・実装日のヒントを見られます
- 経過時間、進捗の自動保存、ギブアップ、結果カードに対応

## 公開URL

https://manyu-a.github.io/chara-quiz/

初回のみ、GitHubの **Settings → Pages → Build and deployment** で以下を選んで保存してください。

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

以後はmainブランチへのコミットが公開ページへ反映されます。ビルドやパッケージのインストールは不要です。

## ファイル

| ファイル | 用途 |
| --- | --- |
| `index.html` | 画面の構造 |
| `style.css` | 見た目 |
| `characters.js` | 使徒の名前・性格・画像など |
| `app.js` | 回答判定、セーブ、ヒント、タイマーなど |

### 使徒を追加する

`characters.js` の `characters` 配列に、ほかの使徒と同じ書式で1行を追加します。

```js
{
  "name": "使徒名",
  "type": "純粋",
  "role": "攻撃",
  "position": "後列",
  "race": "妖精",
  "release": "2026 11/05",
  "image": "画像URL"
}
```

日本語名が重複しないようにしてください。別名や略称を追加する場合は `app.js` の `aliases` を編集します。
